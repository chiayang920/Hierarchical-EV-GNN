4. REPOSITORY / PORTABILITY NOTE
================================

The notebook copies stored under the Git repository's docs/ directory are executed research reference snapshots.

They are not intended to carry the large raw experiment datasets inside Git.

The absolute paths above are specific to the author's current macOS research environment. On another machine:

1. restore an equivalent EVGNN_Research_Artefacts directory structure; or
2. update the notebook data-root definitions to point to the restored local research data.

Do not interpret these machine-specific absolute paths as a portable public-data interface.

The repository should contain the notebooks and this path map, not the large raw training/evaluation package archive.
